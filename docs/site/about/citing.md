# Citing

If bulanik helps your research, please cite the software. The repository carries a
[`CITATION.cff`](https://github.com/tdelphi1981/bulanik/blob/main/CITATION.cff) file, which
GitHub renders as a "Cite this repository" button.

```bibtex
@software{berber_bulanik,
  author    = {Berber, Tolga},
  title     = {bulanik: fuzzy numbers, fuzzy inference and fuzzy MCDM in Python},
  year      = {2026},
  version   = {0.1.0},
  url       = {https://github.com/tdelphi1981/bulanik},
  license   = {MIT}
}
```

Please also cite the original method papers behind the parts you use; the
[references](references.md) page lists every work the library implements, with DOIs.
If you use the [LumiX](../guide/bridge-lumix.md) or [sezgi](../guide/bridge-sezgi.md)
bridge, cite those packages as well.
