# bulanik.mcdm

Multi-criteria decision making. The package re-exports the weighting and
ranking functions and the result types; they are defined in submodules,
rendered one after another below: [results](#bulanik.mcdm.results),
[weighting](#bulanik.mcdm.weighting), [ranking](#bulanik.mcdm.ranking),
[scoring](#bulanik.mcdm.scoring), [outranking](#bulanik.mcdm.outranking),
[fuzzy](#bulanik.mcdm.fuzzy), ranking on fuzzy numbers in
[fuzzy_ranking](#bulanik.mcdm.fuzzy_ranking), the influence analysis in
[dematel](#bulanik.mcdm.dematel) and the best-worst helpers in
[bwm](#bulanik.mcdm.bwm). The solvers for the best-worst method itself live in
the bridges [`bulanik.lumix`](lumix.md) and [`bulanik.sezgi`](sezgi.md).
