# bulanik documentation — design

Date: 2026-11-03. Request (user): "fuzzy kütüphanesini detaylı dokümante et yayımlayacağız" —
document the fuzzy library in detail; it is going to be published.

## Intent
bulanik will be released publicly (PyPI + a public GitHub repo, both later and only with the user's
approval). The documentation must let three readers succeed without reading the source:
1. **Practitioners** (MCDM / fuzzy-logic researchers) who want to run
   a fuzzy AHP/SWARA/TOPSIS/BWM pipeline or a fuzzy controller in a few lines.
2. **Learners** who know Python but not fuzzy logic: a theory track that explains each concept with the
   formulas the code implements and a runnable snippet.
3. **Integrators** using the LumiX (exact optimisation) and sezgi (metaheuristics) bridges.

## Decisions (my calls; the user asked not to be questioned)
- **Tooling mirrors sezgi's site** (same author family): MkDocs 1.6 + Material + mkdocstrings-python
  + markdown-exec + pymdown-extensions, exact pins, in a `docs` dependency group. `mkdocs.yml` at the
  repo root, `docs_dir: docs/site`, `site_dir: site` (git-ignored), `site_url:
  https://tdelphi1981.github.io/bulanik/`. Plugins: search, privacy, offline, markdown-exec,
  mkdocstrings. Light/dark palette toggle like sezgi (primary teal to distinguish the brand).
- **Language: English.** A Turkish translation is a later, separate job.
- **Install text describes the published state**: `pip install bulanik`, `pip install "bulanik[lumix]"`,
  `"bulanik[sezgi]"`, plus "from a checkout" for development. README gets the same text. (Becomes true
  at the PyPI release; listed in the hand-off.)
- **Every code snippet in the docs runs.** Snippets are executed at build time with markdown-exec
  (`exec="on"` + `source="above"` or "tabbed") so output shown is real output. `mkdocs build --strict`
  must pass with zero warnings. A pytest test (`tests/test_docs.py`) runs the strict build when the
  docs group is installed (skipped otherwise), so the normal suite guards the site.
- **Docstrings become Google style** (`Args:`, `Returns:`, `Raises:`, `Examples:`, `References:`) for
  every public symbol, with `>>>` examples that run under `pytest --doctest-modules` (added to the
  pytest config for `src/bulanik`, excluding the bridges when their extra is missing). mkdocstrings
  `docstring_style: google`. Sphinx roles (`:class:` etc.) are replaced by mkdocstrings cross-refs
  (`[TFN][bulanik.TFN]`) or plain backticks. No behaviour changes in source code.
- **Formulas**: rendered with MathJax via `pymdownx.arithmatex` (generic mode). MathJax is loaded from
  cdn.jsdelivr with an exact version; the privacy plugin downloads it at build time so the published
  site is self-contained.
- **Figures**: membership-function shapes, an IT2 footprint of uncertainty, an ANFIS fit and a
  Mamdani output surface/aggregate, generated by scripts in `docs/scripts/` with matplotlib (docs group
  only) into committed SVGs under `docs/site/assets/figures/`. Follow the dataviz skill rules
  (/private/tmp/claude-501/bundled-skills/2.1.296/3fcf240dc6f0a517d53c5d4727f7971e/dataviz/SKILL.md):
  thin marks, one axis, validated categorical palette, legends for ≥2 series, dark-mode legible
  (transparent background, mid-tone colours).
- **References are real and verified.** Every cited work gets full bibliographic data and a DOI that
  was checked (web search/DOI resolver) — no invented citations. One bibliography page; method pages
  link to it.
- **Publication extras** (documentation in the broad sense): `CHANGELOG.md` (0.1.0 entry),
  `CITATION.cff` (mirrors sezgi's: Tolga Berber, ORCID 0000-0002-6487-5581, KTÜ affiliation; version
  0.1.0; repository-code https://github.com/tdelphi1981/bulanik), `CONTRIBUTING.md`,
  `.github/workflows/docs.yml` (build strict + deploy Pages on push to main, mirroring sezgi's, no Rust
  steps), pyproject `[project.urls]` (Homepage/Documentation/Repository/Issues/Changelog) and a
  `Programming Language :: Python :: 3.10–3.13` classifier set. Nothing is pushed or published.

## Site map (nav)
- Home (`index.md`): what bulanik is, feature grid, 10-line taste, where to go next.
- Install (`install.md`): pip/extras/uv, Python versions, checkout install, verifying.
- Quickstart (`quickstart.md`): 5 short executed recipes (numbers, aggregation, a Mamdani tipper,
  fuzzy TOPSIS, BWM weights).
- Concepts (`concepts/`): `conventions.md` (immutability, validation, error types, tolerances and
  boundary projection, named operator families/scores and the naming rule), `choosing.md` (which
  number type / inference system / MCDM method for which problem — decision tables).
- User guide (`guide/`), each page = theory (formulas) + API walkthrough + executed snippets + pitfalls:
  `numbers-triangular.md` (TFN/TrFN), `numbers-orthopair.md` (IFN/PFN/FFN/QROFN),
  `numbers-threepart.md` (spherical/picture/neutrosophic), `aggregation.md` (WA/WG, expert
  aggregation, weights), `sets-and-scales.md` (membership functions, linguistic variables, built-in
  scales), `mamdani.md`, `sugeno-tsukamoto.md`, `type2.md`, `anfis.md`, `weighting.md`
  (AHP, fuzzy AHP, SWARA, entropy, BWM core), `ranking.md` (TOPSIS, VIKOR, WASPAS, EDAS, rank_fuzzy,
  DecisionMatrix), `fuzzy-topsis.md`, `bridge-lumix.md`, `bridge-sezgi.md`.
- Examples (`examples/`): one page per example 01–16 — purpose, source included via
  `pymdownx.snippets` from `examples/`, the real output (executed at build), what to notice.
- API reference (`api/`): one page per module via `::: bulanik.<module>` (numbers, aggregate, sets,
  scales, inference, type2, anfis, mcdm, lumix, sezgi, exceptions where they live).
- About: `references.md` (bibliography), `changelog.md` (includes CHANGELOG.md), `citing.md`,
  `contributing.md`, `license.md`.

## Non-goals
Turkish translation; notebooks; publishing (PyPI, GitHub repo creation, Pages deploy); any library
behaviour change (docstring-only source edits).

## Quality bar
- `mkdocs build --strict` zero warnings; all executed snippets run; doctests pass; full test suite
  green with coverage gate unchanged.
- Every public symbol (everything in each module's `__all__` or documented in README) appears in the
  API reference with a Google-style docstring including at least one runnable example.
- Every guide page states the formulas the code actually uses (checked against the source), cites
  its source, and ends with "Pitfalls" (validation errors a user will hit and why).

## Visual design (added 2026-11-03 on the user's request: "bulanık sayıların görselleştirmelerini çok güzel olmasını istiyorum")
Fuzzy-number visuals are a headline feature of the docs, not decoration. Bar: publication-quality,
cohesive house style, every figure teaches one idea at a glance.
- **House style** in `docs/scripts/_figutil.py`: one validated categorical palette (dataviz validator,
  light and dark), one typography scale, thin 2 px lines, soft translucent fills (alpha ~0.18–0.25)
  under membership curves, recessive grid/axes, direct labels instead of legends where ≤4 series,
  LaTeX-style math labels via matplotlib mathtext, consistent aspect ratios. **Light and dark variants**
  of every figure (`name-light.svg` / `name-dark.svg`), shown with Material's `#only-light` /
  `#only-dark` image suffixes so figures match the reader's theme.
- **Fuzzy-number figure set** (minimum): TFN and TrFN anatomy (l, m, u / a, b, c, d annotated, support,
  core, an α-cut band); α-cut arithmetic (A, B and A+B, A·B as stacked panels showing the interval
  arithmetic per α); defuzzification (centroid / graded mean / mean markers on one TFN);
  orthopair feasibility regions for IFN (q=1), PFN (q=2), FFN (q=3) and q=5 on one plot (nested
  boundaries μ^q+ν^q=1) with sample numbers plotted as points and their hesitancy shown;
  an operator-family comparison (algebraic vs Einstein sum of two IFNs as arrows in the μ–ν plane);
  picture fuzzy numbers on the μ–η–ν simplex (ternary triangle); spherical fuzzy numbers on the
  positive octant of the unit sphere (clean 3-D render, single view angle chosen for legibility);
  neutrosophic numbers as a T/I/F radar or unit-cube view; WA vs WG aggregation of IFNs in the μ–ν
  plane; a linguistic scale (all TFN terms of a built-in scale on one axis, direct-labelled).
- Inference/ANFIS figures (Task 7) and MCDM figures (Task 8: e.g. ranking bar/dot charts, weight
  comparisons) reuse the same house style.
- Figures are generated by scripts and committed; `tests/test_docs.py` (or a sibling test) checks that
  every figure referenced in the docs exists in both variants.

## bulanik.plot (added 2026-11-03 on the user's request: "evet bulanik.plot modülünü de ekleyelim")
A public plotting module, so users get the same visuals as the docs. This is a library feature (the
one exception to "no behaviour change"); the core stays stdlib-only.
- **Packaging:** optional extra `plot = ["matplotlib>=3.8"]`; matplotlib is imported lazily inside
  `bulanik.plot`, and importing it without the extra raises ImportError with the hint
  `pip install "bulanik[plot]"`. matplotlib joins the dev group so the module is tested and counted in
  coverage (gate stays 95%).
- **House style lives here**, not in docs scripts: `bulanik.plot.PALETTE` (validated categorical
  palette, light and dark), `bulanik.plot.theme(name="light"|"dark")` context manager applying the rc
  style, and every plotting function follows it. Docs figure scripts call `bulanik.plot` and only add
  layout/annotation.
- **API (functional; every function takes `ax=None`, creates a figure if needed, returns the Axes,
  never calls `plt.show()`; keyword-only options; validates its inputs with the library's usual
  errors):**
  - `membership(numbers, *, labels=None, alpha_cut=None, fill=True, ax=None)` — TFN/TrFN membership
    functions (one or many), optional α-cut band.
  - `alpha_cuts(number, *, levels=11, ax=None)` — horizontal interval bars per α.
  - `defuzzification(number, *, scores=None, ax=None)` — markers for the number's score functions.
  - `orthopair(numbers, *, q=None, regions=None, labels=None, hesitancy=False, ax=None)` — μ–ν plane
    with feasible boundary curves μ^q+ν^q=1 (regions e.g. (1, 2, 3)) and points.
  - `picture(numbers, *, labels=None, ax=None)` — μ–η–ν ternary simplex.
  - `spherical(numbers, *, labels=None, ax=None)` — positive unit-sphere octant (3-D axes).
  - `neutrosophic(numbers, *, labels=None, ax=None)` — T/I/F radar (polar axes).
  - `variable(var_or_scale, *, x=None, ax=None)` — every term of a LinguisticVariable or built-in
    scale, direct-labelled; optional crisp input marker with its membership degrees.
  - `mamdani_output(fis, inputs, output=None, *, ax=None)` — clipped consequents, aggregate, crisp value.
  - `surface(fis, output=None, *, resolution=41, ax=None)` — 2-input control surface (3-D) or 1-input curve.
  - `it2_set(mf_or_term, *, ax=None)` — footprint of uncertainty (upper/lower MF, shaded FOU).
  - `ranking(result, *, ax=None)` and `weights(result, *, ax=None)` — MCDM results as sorted dot/bar charts.
  Exact names/signatures may be refined by the implementer against the real classes; record rulings.
- **Tests:** Agg backend; each function on representative inputs returns Axes with the expected
  artists (line count, labels, limits), rejects bad inputs, works in both themes; a smoke test saves
  each to SVG in tmp. No pixel-comparison tests.
